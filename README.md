## Features
...
- Charsets: ASCII, binary, blocks
- Green terminal mode or real colors
- Adjustable resolution (40–160 columns)
- Runs entirely in your browser; video never leaves your device

## How it works
The webcam feed is drawn onto a tiny hidden canvas (one pixel per character).
Each pixel's brightness picks a character from a ramp (` .:-=+*#%@`), and the
result is drawn as text on the display canvas every frame.

## Built with
HTML, CSS, JavaScript (Canvas API, getUserMedia)
